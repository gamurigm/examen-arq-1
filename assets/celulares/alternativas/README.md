# Fotografías alternativas

27 imágenes descargadas de Wikimedia Commons; junto con las tres fotos de Pexels del directorio padre completan 30 assets. No se alteró el catálogo SQL ni las fotos existentes.

`fuentes.json` identifica cada imagen, autor, página original, licencia, URL de licencia, descarga y SHA-256. Cada archivo mantiene su licencia indicada; la licencia del código no la sustituye. Se descargaron miniaturas suministradas por Wikimedia, sin edición local.

Reproducción: `python scripts/DescargarFotos.py`. Las imágenes son ilustrativas y no son capturas de la aplicación.
