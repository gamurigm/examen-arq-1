# Cliente escritorio WPF

Consume la API de la comercializadora y permite catálogo, ventas y consultas. Para requisitos y ejecución, consulte `../05. DOCUMENTACION/ManualTecnico.md`.

La vista nativa está en `MainWindow.xaml`; catálogo, ventas, reintentos y consultas pasan por `Controladores/ControladorEscritorio.cs`. El cliente HTTP compartido está en `../04. COMPARTIDO/Celulares.Cliente/Servicios`.
